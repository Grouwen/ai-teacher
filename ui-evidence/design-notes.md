# AI教学员 · 前端改版设计说明

## 北极星

**一本写给你一个人的教材，配一支红笔。** 读的时候像纸质讲义，动笔的时候像老师在页边批注。

## 第二版：删释义，让结构说话

页面上的解释性文案基本删完：每页只留标题、数据与操作。流程由左栏四步目录说明，章节顺序由编号列表说明，题量由题号导航和「已答 / 10」说明，下一步由按钮说明。

- 摸底页改成单列 640px：标题在上，登记表在下，不再用左栏解释判级。
- 规划页只留路线和「重新生成 / 确认规划」；操作条在草稿加载出来后才出现。
- 学习页删掉「先读后写」「每章 10 题」「看答案前先写一遍」这类提示，也删掉页脚。
- 进度页删掉断点续跑说明与标题旁的重复统计；完成度环、章节账本和错题清单自己说话。
- 追问次数、旧题替换、答题记录保留这类**操作后果**保留，它们是约束，不是释义。
- 静态文案按 `humanizer-zh` 的规则过了一遍：删掉空泛铺垫、假对比和客服腔，保留否定、条件、次数与数据边界；没有为了「像人」添加原文没有的事实。

## 判断依据

- 品类：本地单用户 AI 家教，路径固定为「摸底 → 规划 → 讲解 → 练习 → 进度」。
- 用户：有明确产出的成年学习者（本例目标为做出一个 agent 项目），每天 0.5–2 小时，注意力给内容和练习，不给界面。
- 首屏任务：学习页要在同一屏里回答「这章讲什么 / 我该写什么 / 我写到哪了」。
- 标杆拆解：Duolingo 给进度感但过度游戏化；Brilliant 的练习卡清楚但偏轻；传统教材版心耐读、有页码与编号；Linear 的克制与留白适合工具界面。
- 偏离理由：不做游戏化积分和卡通插画——用户是成年自学者，奖励来自「讲清楚了」和「批改到位」；不做仪表盘式大卡片堆叠——这一页的主角是文字和题。

## 方向卡

- 名称：**讲义与红笔**
- 骨架：左侧深墨色书脊（品牌 + 四步目录 + 状态），右侧米白纸面版心；学习页正文 640px 阅读列 + 252px 页边栏（追问）。
- 字体：标题用中文衬线（STZhongsong / 宋体），正文用系统黑体，编号与元信息用等宽；标题不描边不加粗，靠字号与留白立层级。
- 色彩：纸 `#f5f0e6`、墨 `#211d18`、朱砂 `#a83226`（只给章节号、批改、关键标记）、批改绿 `#2f6a4f`；不使用渐变主视觉。
- 主视觉：没有照片。辨识度来自编号、细线、双圈印章、难度刻度、书页留白；代码块作为书中的「插图」，采用深墨底。
- 图像需求：无（本地离线应用，内容优先，照片只会增加噪音）。

## 版式决定（含默认做法说明）

- **眉标只留一处**：学习页章节加载后显示「第 N 章 · 共 M 章」，承担书眉职责。摸底、规划、进度页不设眉标，标题直接立住；检查工具按「标题上方的眉标」提示这一处，属有意保留。
- **彩色单侧边线**：只出现在三处语义块——本章目标（朱砂 2px）、批改反馈（对绿 / 错朱 3px）、Toast（状态色 3px）。它是「红笔页边」的转译，不是卡片装饰。
- **操作条**：桌面端放在内容末尾，读完再确认；移动端压缩成一行吸底（64px）。没有内容时不显示，避免「确认」悬在空页上。
- **摸底页**：单列 640px，标题 + 登记表。桌面不再用左栏填充判级说明，移动端首屏直接进入表单。
- **判级结果卡**：L3 印章、经验 / 掌握 / 每日时长、目标、章节数、一个「去确认规划」按钮。不再重复列出全部章节，清单属于规划页。
- **练习**：10 题是长页，顶部加题号导航（答过即填墨），可跳题并聚焦输入；计数明确为「本次已答」，避免把会话内状态说成总进度。
- **代码块**：没有示例代码时整块隐藏，避免空框。
- **页脚删除**：原页脚重复四步流程和「本地单用户应用」，与左栏和页内信息重复。

## 关键状态

- 摸底：未选完 / 提交中 / 判级结果卡（L 级印章 + 经验 / 掌握 / 时长）。
- 规划：生成中骨架 / 章节清单（已完成、学习中、待学习）/ 生成失败可重试 / 无草稿时只留空状态。
- 学习：未完成摸底的空状态 / 已规划待选章 / 章节切换 / 讲解 + 代码 / 追问用尽 / 逐题批改 / 标准答案。
- 进度：完成度环 / 章节账本 / 错题清单 / 损坏与重置。

## 动效（三处）

1. 页面头部与正文入场的 8px 上移淡入（420–500ms）。
2. 批改反馈与追问答复展开：轻微上移 + 印章缩放入场。
3. 按钮按下 1px 下沉、链接下划线偏移、Toast 上滑；全部在 `prefers-reduced-motion` 下关闭。

## AI 生成时的加载态

生成可能持续几十秒，按钮文字不够用，所以每个生成入口都有可见的等待状态：

- **摸底提交**：按钮转圈，表单下方出现「正在判级并排课…」的加载卡（朱砂转环 + 四行纸色微光）。
- **规划生成 / 重新生成**：清单顶部出现「正在生成学习路线…」，下面保留三块骨架条；成功后骨架换成章节行。
- **进入章节**：先按章节按钮上的标题把页头立住，正文位置显示「正在写第 N 章的讲解与题目…」；讲解和练习暂时收起，成功后一起出现。失败时同一位置换成错误信息和「重试」，不留下空白页。
- **批改 / 追问 / 重新出题**：按钮转圈，对应反馈区、答复区或题目区出现一行「正在批改… / 正在答复… / 正在重新出题…」。重新出题期间旧题收起，失败则恢复。
- 所有转环与微光都走 CSS，未加图片或库；`prefers-reduced-motion` 下动画停止，状态文字仍保留。

## 设备与验收

- 目标视口 1440×900；移动端 390×844 单列，章节目录转横向滚动。
- 中文正文 15.5–16px、行高 1.95；桌面阅读列 638px / 约 40 字一行，移动 312px / 约 20 字一行；正文对比度 ≥4.5:1。
- 不引入构建链和第三方库，沿用原生 JS + fetch + Jinja2；API 契约不变。
- 整页高度（截图时的 9 章数据）：1440 下摸底 1152 / 规划 1695 / 学习 6122 / 进度 1243；390 下 1269 / 2816 / 7490 / 1586。判级结果页另加：1440 1392、390 1535。
- 桌面操作条位于内容末尾（规划 y≈1576、进度 y≈994），移动端吸底；无横向溢出（文档宽 = 视口宽）。

## 视觉验证边界

本会话模型不能读取图片，也没有可用的视觉评审员，因此**未对实际像素观感做独立评审，也不给视觉评分**。以上结论来自截图工具的结构检查、运行时布局指标和交互断言；色彩、字重、间距的最终观感仍建议人工过一眼。
